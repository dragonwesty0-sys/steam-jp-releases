# Steam新作棚

日本語対応の発売済みゲームを表示します。Steamストアの日本語対応検索の1ページ目を6時間ごとに取得し、Steam App IDで重複を除いて蓄積します。全期間のゲームを遡及収集する構成ではありません。価格は各ゲームを最後に取得した時点の日本円価格です。取得範囲外になったタイトルの価格は最後の確認時点の値を保持します。

Steamストアの公開検索HTMLを使用するため、仕様変更やアクセスエラーが起こった場合は前回の一覧を保持します。日本語UI・字幕・音声の内訳はSteamの各商品ページで確認してください。ジャンルはSteamタグから分類し、未分類は「その他」と表示します。

## 公開

Cloudflare Pagesで本番ブランチを `main`、出力ディレクトリを `dist`、フレームワークなし、ビルドコマンドを `sh build.sh`で接続します。GitHub Actionsの「Refresh Steam listings」から手動更新もできます。
